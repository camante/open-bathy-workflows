This directory holds scripts and experiments that are not part of the current default `bathy_main.py` execution path.

- `likely_unused/` – scripts that are not referenced by the current pipeline entrypoints (`bathy_main.py`, `sdb_main.py`, `xs_builder.py`, `xs_infer_bathy_raster.py`, `fusion.py`).

If you discover one of these is still needed for your workflow, you can move it back to the repo root (or update imports/calls accordingly).
